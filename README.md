# 口述影像脚本排演台

这是面向口述影像编剧、配音排演员和无障碍内容审校员的浏览器工作台。它把影片时间轴中的对白空隙转化为可写稿、可排演、可逐项审校并可发布的旁白脚本，使用确定性时间规则防止旁白遮盖对白，并保留提示版本、实读测量、审校理由与发布摘要。服务重启后可从项目清单恢复任意制作项目，继续使用当前修订号工作。

## 主要流程

项目依次经历 `DRAFT`、`TIMELINED`、`WRITING`、`REHEARSING`、`REVIEWING`、`REVISING`、`APPROVED` 和 `RELEASED`。时间轴必须先登记场景，再登记对白、音乐强调或其他占用区间；系统合并占用区间并计算满足最小留白的候选窗口。提示只能落入候选窗口，提交排演前会检查边界、占用重叠、阅读容量与阻断项。

排演记录固定的提示版本集合、实际起止时间、实读时长、停顿和问题。工作台按当前提示逐项生成实读录入表，并对相邻轮次给出时长、窗口偏差和问题数对比；版本不一致时明确标记不可直接比较。审校员可以接受、要求修订或驳回；后两种处置必须填写理由。改稿会使旧排演和旧决定失效，必须重新校验和排演。批准后才能生成不可替换的发布快照，并下载 JSON 或 WebVTT；下载前服务会重新校验 `content_hash`。

## 架构与数据

- `internal/domain`：聚合、实体、状态机、不变量与稳定摘要。
- `internal/timeline`：区间归一化、候选窗口、阅读容量和排演测量规则。
- `internal/store`：每项目串行提交、`expectedRevision` 乐观并发、`idempotencyKey` 幂等结果、本地 JSON 快照和确认日志恢复。
- `internal/workflow`：建档到发布的唯一用例编排及 JSON/WebVTT 导出。
- `internal/web`：原生 HTML、CSS、JavaScript 页面和同源 JSON API。
- `cmd/server`：配置、真实 HTTP 生命周期、优雅关闭和全流程自检。

生产运行产生的快照默认写入 `data/snapshots/`，操作日志写入 `data/operations.jsonl`。提交会先同步临时快照并原子替换正式文件，再写入已确认日志；服务启动时重放已确认记录。

## 构建与运行

要求 Go 1.22 或更高版本，不需要 Node.js 或外部服务。

```text
go build ./cmd/server
go run ./cmd/server -addr=127.0.0.1:19081
```

浏览器访问 `http://127.0.0.1:19081/`。默认地址是 `127.0.0.1:19081`，可通过 `-addr=127.0.0.1:<port>` 选择其他回环端口；服务拒绝空主机、通配地址、非回环地址与非法端口。使用 `-data=<path>` 可选择持久化目录。

## 测试与自检

运行全部测试：

```text
go test ./...
```

运行真实 HTTP 全流程自检：

```text
go run ./cmd/server -selfcheck -addr=127.0.0.1:19081
```

自检使用临时数据目录，实际启动指定的回环监听，通过 HTTP 完成建档、时间轴、两版提示差异、校验、排演、退修、改稿、重新排演、审校批准、发布以及双格式下载校验，然后优雅关闭并自行退出。

## API 使用约定

写请求的 JSON 必须带 `expectedRevision` 和 `idempotencyKey`，创建项目只需 `idempotencyKey`。过期的 `expectedRevision` 返回 `409` 和当前修订号；重复提交相同幂等键与操作会返回首次业务结果。字段或状态规则错误返回 `422`。页面使用的全部 API 均为同源路径，健康检查位于 `GET /healthz`。
